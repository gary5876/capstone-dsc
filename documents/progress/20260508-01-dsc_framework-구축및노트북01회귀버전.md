## 1. dsc_framework/ 디렉토리 구축

ADR-013에 따라 우리 산출물을 외부 HPI 패키지(`dq4ai/`)에서 분리.

| 파일 | 용도 |
|---|---|
| `__init__.py` | public API export |
| `shared_metrics.py` | 6개 공통 메트릭 (completeness, uniqueness, validity, consistency, outlier_ratio, feature_correlation) — 두 cell이 공유하는 단일 출처 |

| `column_detection.py` | auto_detect_columns(df) → (target, num_cols, cat_cols, task), detect_task(target_series) |
| `router.py` | compute_dsc(df, task=None) 통합 진입점, select_profile |

| 영역 | 분류 (v4) | 회귀 (v5) |
|---|---|---|

### 데이터셋 사전등록

| 데이터셋 | 행수 | target | 수치형 | 범주형 | drop |
|---|---:|---|---:|---:|---|
| CaliforniaHousing | 20,640 | MedHouseVal | 8 | 0 | - |
| BikeSharing | 17,379 | cnt | 7 | 5 | instant, dteday, casual, registered |
| WineQuality | 6,497 | quality | 11 | 0 | - |

**Bike Sharing leakage 방지**: `casual + registered = cnt` 관계가 있어 두 컬럼을 명시적으로 제거. 또 `instant`(행 인덱스), `dteday`(날짜 문자열)도 학습 부적절하여 제거.

### 4-2. 모델 베이스라인 R² (CaliforniaHousing 검증용)

| 모델 | R² | 시간 |
|---|---:|---:|
