## 1. 각 평가 파라미터를 그 지표로 정한 이유

### 1-1. 설계 대전제 두 가지

**(A) 절대 품질 지표 — reference 없이 그 자체로 0~1 (ADR-009)**
v3.2의 `value_accuracy`(가중치 0.30)는 "원본 분포 대비 거리(KS/TVD)"라서 baseline에서 항상 1.0이 나오는 **drift 측정 도구**였다. "DSC = 데이터 품질 점수"라는 제품 정체성과 모순. v4에서 이를 제거하고, reference 없이 데이터 자체로 ML 학습 가능성을 보는 **label_consistency + feature_informativeness**로 대체했다.
출처: `documents/decisions/ADR-009-DSC엔진v4-절대품질지표교체.md`

**(B) Task-conditional "강한 버전" — 지표 정의식 자체를 (data_type, task)별로 재정의 (ADR-011)**
가중치만 바꾸는 약한 버전은 "v4 모델 프로파일 확장"으로 보여 framework 주장이 약하다. 그래서 **정의식을 셀마다 재정의**한다. 예: `completeness`는 정형=결측, 이미지=마스킹 픽셀, 텍스트=`[MASK]`/`[PAD]` 토큰. `feature_correlation`은 정형=컬럼 Pearson, 이미지=ResNet18 임베딩 cosine, 텍스트=DistilBERT 임베딩 cosine.
학술 근거: Wang & Strong 1996 "fitness for use"(contextual DQ), Heinrich et al. 2018 메트릭 5요건(R1 스케일 존재·R4 건전 집계), Mohammed et al. 2022(동일 오염이 task별로 다르게 작용).
귀결: **셀 간 절대값 비교 금지**(cell-relative). 같은 0.7도 분류 셀과 회귀 셀은 의미가 다름.
출처: `documents/decisions/ADR-011-Task-conditional-Framework-강한버전채택.md`

### 1-2. 지표별 — 무엇을 측정 / 왜 / 잡는 문제

| 지표 | 무엇을 측정 | 왜 이 지표인가 (잡는 데이터 문제) |
|---|---|---|
| **completeness** | 1 − 결측·마스킹 비율 | 결측 많으면 학습 자체 불가. 가장 기본 전제 → 최고 가중치급 |
| **uniqueness** | 1 − 중복 비율 | 중복은 실제 정보량을 줄이고 학습 분포를 왜곡 |
| **validity** | 형식/인코딩/파싱 성공 비율 | 형식 오류는 파이프라인을 즉시 중단시킴(필수 체크) |
| **consistency** | 표현 일관성(범주 표기·길이·색공간) | "M/Male/m" 혼재 등 → 특성 엔지니어링 오류·전처리 비용 |
| **outlier_ratio** | 1 − IQR 기반 이상치 비율 | 극단값은 정규화 기준·gradient를 왜곡. IQR 고정으로 자기참조 회피 |
| **feature_correlation** | 1 − 고상관 피처/차원 비율 | 다중공선성·표현 공간 낭비. 정보 독립성 신호 |
| **class_balance** (분류) | min(class)/ideal | 극단 불균형이면 다수 클래스만 학습. 분류 전용 |
| **label_consistency** (분류) ⭐ | k=5 이웃 라벨 일치율(chance 보정) | **라벨 노이즈 + 결정경계 모호도**를 직접 측정 = ML 분류 가능성 |
| **feature_informativeness** (분류) ⭐ | mutual_info_classif / H(Y) | 피처가 라벨과 무관하면 MI≈0 → 학습 불가. 노이즈 주입 시 정확히 하락 |
| **target_distribution_quality** (회귀) | target 10-bin 정규화 엔트로피 | 분류 class_balance의 회귀 대응. 분포 편향 시 모델이 평균값만 예측 |
| **target_smoothness** (회귀) ⭐ | 이웃(임베딩 k=5) target std 보수 | label_consistency의 회귀 대응. "유사 입력→유사 출력" = 결정곡면 매끄러움 |
| **feature_informativeness_reg** (회귀) | mutual_info_regression / log(bins) | feature_informativeness의 회귀 대응 |
| **completeness_image / _text** ⭐ | 마스킹 픽셀 / `[MASK]`·`[PAD]` 토큰 비율 | 모달리티 내재 손실. 복원 불가 영역은 학습 불가 |
| **sample_quality_image** ⭐ | blur(Laplacian)·contrast 결합 | 흐림·저대비는 feature 추출 전 이미 정보 손실 |
| **sample_quality_text** ⭐ | TTR(어휘 다양성)·길이 적절성 | 단어 반복·과단문은 맥락 정보 부족 |

⭐ = v4/v5에서 ML 학습 가능성을 직접 보려고 신설·재정의한 핵심 지표.

소스 직접 확인: `dsc_framework/{classification,regression,image,text,text_cell_regression}_cell*.py`

| consistency | 0.10 | 0.10 | 0.05 | 0.05 | 0.05 |

> ⚠️ **정형 분류 r=0.598은 v4 엔진(정규화 전 합 1.25) 기준**이며, 위 v5 셀 가중치(합 1.00)와는 수치가 다르다. v5는 같은 9개 지표를 셀로 재구성한 것.

### 3-3. 파라미터별 오염 테스트 — 실측 (텍스트 회귀, sst5)

`results/text_dsc_sweep.csv`에서 직접 추출 (baseline DSC=76.2). 각 오염기가 표적 지표를 떨어뜨리는지 검증:

| 오염기 | 표적 지표 | level 0.0 → 0.9 (지표) | DSC 0.0 → 0.9 | 신호 |
|---|---|---|---|---|
| completeness_text | completeness_text | 1.000 → **0.101** | 76.2 → **56.1** | 강 (Δ−20) |
| target_distribution_skew | target_distribution_quality | 0.679 → **0.555** | 76.2 → 75.8 | 약 |
| target_noise | target_smoothness | 0.226 → 0.246 | 76.2 → 78.5 | 미반응 |
| noise_injection_text | (임베딩계) | — | 76.2 → 74.4 | 약 |
| word_shuffle | sample_quality_text | 0.882 → 0.895 | 76.2 → 76.2 | 미반응(의도) |

**솔직한 진단:** completeness는 깔끔한 강신호. 반면 **target_smoothness가 sst5에서 baseline부터 0.226으로 낮아** target_noise를 줘도 더 안 떨어진다(floor effect). 이 지표 가중치(0.20, 최대)가 baseline DSC를 끌어내리는 구조라, 운영 시 LLM 가중치 생성기가 이 비중을 어떻게 잡느냐가 held-out 상관에 직접 영향. word_shuffle 미반응은 BoW 지표엔 변별력 없는 의도된 동작. (이 sst5 baseline 76.2는 본 자료의 라이브 시연값 75.25와 일치 → 재현성 확인.)

### 3-4. Live/Dead 지표 — 표준 벤치마크의 한계

표준 공개 데이터셋은 이미 깨끗해서 일부 지표가 baseline부터 ~1.0이라 오염 전까지 거의 안 움직인다("dead"):

| 셀 | Live (오염에 반응) | Dead (거의 1.0 고정) |
|---|---|---|
| 정형 분류 | completeness, feature_informativeness, label_consistency, class_balance | consistency, feature_correlation |
| 이미지 분류 | completeness_image, sample_quality_image, label_consistency | uniqueness, validity, feature_correlation |
| 텍스트 분류/회귀 | completeness_text, target/label 계열, class_balance | uniqueness, validity, feature_correlation |
