### 1-2. pymfe MFEComplexity 모듈 — 22 measure 카테고리

(공식 docs 기준, 2026-05-07 검증)

| 카테고리 | measure | 정의 |
|---|---|---|
| **Feature Overlapping** | F1 | Maximum Fisher's discriminant ratio |
| | F1v | Directional-vector maximum Fisher's discriminant ratio |
| | F2 | Volume of the overlapping region |
| | F3 | Feature maximum individual efficiency |
| | F4 | Collective feature efficiency |
| **Linearity** | L1 | Sum of error distance by linear programming |
| | L2 | OVO subsets error rate of linear classifier |
| | L3 | Non-linearity of a linear classifier |
| **Neighborhood** | N1 | Fraction of borderline points |
| | N2 | Ratio of intra/extra class NN distance |
| | N3 | Error rate of 1-NN classifier |
| | N4 | Non-linearity of k-NN classifier |
| **Dimensionality** | T1 | Fraction of hyperspheres covering data |
| | T2 | Average number of features per dimension |
| | T3 | Avg PCA dims per points |
| | T4 | Ratio of PCA dim to original dim |
| **Class Balance** | C1 | Entropy of class proportions |
| | C2 | Imbalance ratio |
| **Network** | LSC | Local set average cardinality |
| | ClsCoef | Clustering coefficient |
| | Hubs | Hub score |
| | Density | Average density of network |

### 1-3. 왜 이 라인이 paper에서 critical인가

- **Class Balance(C1, C2)**: DSC의 `class_balance` 차원과 직접 등가. 정의식 비교 표 필수.
- **Feature Overlapping(F1~F4)**: DSC의 `feature_accuracy` 차원과 인접. F1은 Fisher discriminant ratio로 정의 명확 → DSC `feature_informativeness`와 비교 가능.
- **Neighborhood(N1~N4)**: DSC의 `label_consistency` (k=5 KNN 기반)와 직접 등가. N3은 1-NN error rate로 거의 같은 metric.

**Reviewer 1번 challenge**: "Lorena et al. 2018의 22 measure를 평균하면 DSC와 비슷한 통합 점수가 나오지 않나?" → 이 비교 실험 안 하면 paper 약함. **pymfe 설치 1줄 + 비교 실험 1주.**

### 2-2. Budach et al. 2022 — 직접 선행연구 정독 (이미 인용 #9, 본문 추가 분석)

**핵심**: 6 차원 × 9 데이터셋 × 15 모델 × 3 시나리오의 systematic study. **차원별 분석만**, 통합 점수 없음.

**6 차원** (DSC와 직접 매칭됨, 같은 DQ4AI 코드 모태):
일관된 표현, 완전성, 피처 정확도, 타겟 정확도, 고유성, 클래스 불균형.

**핵심 발견 4개**:
1. 타겟 정확도가 가장 큰 영향 (라벨 20% flip → F1 최대 10% 감소)
2. 테스트 오염 > 트레인 오염 (테스트는 비선형 급락)
3. 고유성은 거의 영향 없음
4. "적응의 역설" — train+test 같은 방식 오염이면 오히려 성능 향상 사례

**저자 명시 future work** (= DSC가 채울 자리):
> "이득을 보기 위해 우리는 단순 모델, 합성 오염, **개별 데이터 품질 차원에만** 실험을 제한했다"

→ DSC는 통합 점수로 multi-dimension 다룸. **그들의 self-acknowledged 한계를 채우는 것.**

### 2-3. Northcutt et al. 2021 (Confident Learning, 인용 #10) — 보강

**핵심 method**: Out-of-sample predicted probability + class-conditional noise matrix → label error 식별.

**중요 발견**:
- **Paper 자체에는 dataset-level score 없음.** sample-level diagnostic이 핵심.
- **cleanlab 라이브러리에 추가 구현된 것**: `health_summary()` → `overall_label_health_score` (0~1 단일 점수). CIFAR-100=0.82, MNIST=1.00 등 예시. **알고리즘은 공식 docs에 미공개.**
- **한계 명시**: Class-conditional noise 가정 (label-dependent on features면 깨짐). Label noise만 다룸 — feature noise, class imbalance, missingness 등은 범위 밖.

**Reviewer 관점**: cleanlab은 너의 가장 직접적인 baseline. 같은 표본에 cleanlab health_score 돌려서 DSC와 r 비교 실험 필수.

### 2-4. Mazumder et al. 2022 (DataPerf, 인용 #17) — 보강

**5 트랙**: Selection for Speech, Selection for Vision, **Debugging for Vision**, Data Acquisition, Adversarial Nibbler.

**Tabular 트랙 없음.** Appendix에 "future possibility: active learning for tabular data"로만 언급.

**Baseline에 cleanlab 포함됨** (Speech selection 트랙) → cleanlab이 이미 community-wide baseline. DSC가 cleanlab과 비교해야 하는 정당화는 DataPerf가 직접 제공.

**Bonus 옵션**: paper와 별도로 DSC를 DataPerf에 새 tabular debugging 트랙으로 propose. NeurIPS workshop accept된 다음 community contribution으로 등록 가능 — 외부 검증 시그널.
