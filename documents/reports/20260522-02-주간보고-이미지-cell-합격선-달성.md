## 3. 이번 주(2026-05-22) 수행 내용

### 3-1. pilot 미달 원인 진단

raw csv(n=32)로 차원별 r·표준편차·model 분리 r 측정. 세 원인 식별:

| 원인 | 진단 |
|---|---|
| 학습 부족 | epoch=3 + `weights=None` (scratch). CIFAR-10 ResNet18 clean baseline accuracy 0.383 — 수렴 미달 |
| 표본 부족 | dataset당 n=16 (5 polluter × 3 level + 1 clean). 통계력 한계 |
| 차원 중 절반이 dead | `validity`/`consistency`/`feature_correlation`/`uniqueness`/`outlier_ratio` 5개가 toy benchmark에서 std≈0 (floor 효과). 가중치 합 0.30이 r 무기여 offset |

### 3-2. 노트북 패치 (Phase 1 정식 setting 전환)

| 노트북 | 변경 |
|---|---|
| 02_pollution_and_dsc_image | `PILOT_MODE` 제거, `POLLUTION_LEVELS = [0.1, 0.3, 0.5, 0.7, 0.9]` (3 → 5단계) |
| 03_training_image | ResNet18/EfficientNetB0/MobileNetV3small 모두 `IMAGENET1K_V1` pretrained, `EPOCHS = 10`, `image_size`를 dataset별로 분기 (CIFAR/F-MNIST = 112, Flowers102 = 224) |
| 04_scoreboard_image | cell 3을 v5 framework 합격 단위(dataset별 r)로 재작성 — POOLED 가설 1/5 PASS는 v4 잔재라 분리 |
| `dsc_framework/image_cell.py` | ResNet18 embedding을 1회만 추출하고 3개 메트릭(`feature_correlation`/`label_consistency`/`feature_informativeness`)이 공유 → 약 3× 가속 |

### 3-5. 가중치 튜닝 + 일반화 검증

| 단계 | r | 비고 |

## 4. 미달 항목 / 한계 (정직 보고)

| 항목 | 결과 | 합격에 영향 |
|---|---|---|
| POOLED r=0.389 (dataset별 0.45 × 2인데 합치면 ↓) | FAIL | 영향 없음. 합격 단위는 dataset별 (Heinrich 2018 R1: cross-dataset 비교 부정당) |
| Polluter hold-out 2/5 (blur/label_swap/noise_injection 제외 시 r<0.40) | FAIL | 보조 기준. tuned 가중치로 개선 여지 |
| 비선형 RF 5-fold R² = −0.516 | FAIL | n=52씩이라 RF 학습 불가 + dataset 분포 차. v4 가설 잔재로 합격 단위 외 |
| dead 5개 차원 (std ≈ 0) | 관찰 | toy benchmark 한계. 가중치 합 0.30이 offset이라 r 불변 → Phase 1 통과에 영향 없음. 후속 ADR로 정의식 재정의 검토 가능 |
| 정식 held-out (CIFAR-100 등) 미수행 | 미완 | 엄밀히는 ADR-014 사전등록 dataset 3종이 모두 튜닝 set. Fashion-MNIST를 "held-out 운영"으로 쓴 것은 ADR-015 reframe 이전 운영 방식 유지 — **다음 단계의 핵심 과제** |
