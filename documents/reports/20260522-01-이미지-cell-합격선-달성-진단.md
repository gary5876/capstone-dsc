## 1. 핵심 결과 — **합격선 r ≥ 0.40 달성**

| Dataset | n | Pearson r | Spearman ρ | p (Pearson) | 합격 (r≥0.40) |
|---|---:|---:|---:|---:|:---:|
| CIFAR-10 (튜닝) | 52 | **+0.4486** | +0.532 | 8.5e-04 | **PASS** |

**default 가중치(ADR-014 사전등록 fallback)**만으로 두 dataset 각각이 합격선 통과.

> POOLED FAIL은 두 dataset의 score-accuracy 회귀선 기울기/절편이 다르기 때문이며, Heinrich 2018 R1의 "cross-cell 비교 부정당" 원칙과 동일 라인. plan 20260511-01의 합격 단위가 **dataset별 r**이므로 합격 판정에 영향 없음.

## 3. 차원 구조 — live 5 / dead 5

### 3-1. dead 차원 (toy benchmark 한계, 가중치 합 0.30)

| 차원 | 전체 std | 원인 |
|---|---:|---|
| `validity` | 0.0000 | torchvision 이미지는 모두 PIL 로드 성공 |
| `consistency` | 0.0000 | CIFAR/F-MNIST 모두 통일된 size/mode |
| `feature_correlation` | 0.0000 | ResNet18 임베딩 512차원의 corr>0.95 페어 거의 없음 |
| `uniqueness` | 0.0008 | torchvision 벤치마크는 중복 거의 없음 |
| `outlier_ratio` | 0.0073 | intensity outlier 거의 없음 |

이 5개는 ADR-014 정의식이 toy dataset에서 floor에 걸린 결과로, 정의식 자체는 그대로 두되 r에 기여 없음 (offset → score-acc 관계의 affine transform).

### 3-2. live 차원 (실제 r 형성)

#### 차원별 r (POOLED n=104, default 가중치 기준)

| 차원 | r | p | std | 비고 |
|---|---:|---:|---:|---|
| `label_consistency` | **+0.466** | <1e-7 | 0.234 | embedding k-NN, 가장 강한 단일 차원 |
| `sample_quality_image` | **+0.401** | 2e-5 | 0.196 | blur + contrast 결합 |
| `feature_informativeness` | +0.325 | 8e-4 | 0.029 | embedding → label MI |
| `outlier_ratio` | +0.184 | 0.06 | 0.007 | dead에 가깝지만 약신호 |
| `class_balance` | +0.021 | 0.84 | 0.095 | 변동은 있지만 r 무관 (clean test 평가라 학습셋 불균형 효과가 깨끗하게 안 잡힘) |
| `uniqueness` | −0.208 | 0.03 | 0.001 | std 미미, 음의 r은 우연 가능 |
| `completeness_image` | **−0.394** | <1e-4 | 0.242 | **마스킹이 강할수록 정확도가 오히려 향상** — Fashion-MNIST는 검은 배경 마스킹이 약화 신호로 작동 |

#### completeness_image의 음의 r — 흥미로운 관찰

- Fashion-MNIST는 원본 자체가 검은 배경 → "마스킹 비율"이 base가 높음 (default 0.48)
- 추가 폴루션이 가해져도 모델 인식에 큰 손상 없음 (모델이 이미 검은 배경에 적응)
- 반면 CIFAR-10은 배경이 다양해서 마스킹이 학습에 더 해로움
- 두 dataset 합치면 마스킹 강도와 정확도가 역상관처럼 보임 → POOLED의 r=0.389 발목을 잡는 원인 중 하나

후속 ADR에서 `completeness_image` 정의식을 dataset 배경 분포 기반으로 보정하면 r 추가 상승 가능.

## 4. 가중치 튜닝 결과 (참고용, freeze 아님)

CIFAR-10에서 numerical optimization (Nelder-Mead × 20 trials), live 차원만 자유롭게:

| 차원 | default | tuned | 비고 |
|---|---:|---:|---|
| feature_informativeness | 0.100 | **0.400** | weight bound [0.01, 0.60] 안 |
| label_consistency | 0.200 | 0.118 | |
| class_balance | 0.100 | 0.115 | |
| sample_quality_image | 0.150 | 0.059 | |
| completeness_image | 0.150 | 0.007 | 음의 r이라 거의 0으로 |
| (dead 5개) | 0.30 | 0.30 | 그대로 (offset) |
| **합** | 1.00 | 1.00 | |

### 일반화 검증

| Dataset | default r | tuned r | Δ |
|---|---:|---:|---:|
| CIFAR-10 (fit) | +0.449 | +0.504 | +0.055 |
| Fashion-MNIST (held-out) | +0.447 | **+0.578** | **+0.131** |
| POOLED | +0.389 | +0.584 | +0.195 |

- 옛 pilot의 generalization gap +0.487 (over-fit 명확)
- 정식 튜닝의 gap −0.074 (held-out에서 오히려 더 높음 — 일반화 정상)
- 차이 원인: pilot은 n=32 + scratch라 noise가 가중치에 fit되었고, 정식은 n=52 fit + pretrained로 안정

> **단**, 이 튜닝은 ADR-015 정신상 정식이 아님 (numerical optimization, LLM 아님). 정식 운영은 LLM 가중치 생성기가 dataset metadata만 보고 비슷한 비율을 만들어내는지 검증해야 함. 위 결과는 **목표 가중치 비율의 lower-bound reference**로 활용.

## 6. 미달 항목 + 한계

### Polluter hold-out 2/5

| 제외 | r (POOLED default) | 합격 |
|---|---:|:---:|
| blur | +0.331 | FAIL |
| class_balance | +0.442 | PASS |
| completeness_image | +0.445 | PASS |
| label_swap | +0.288 | FAIL |
| noise_injection | +0.391 | FAIL |

- POOLED default 기준이라 dataset 분리하면 양상 다를 수 있음
- tuned 가중치로 재측정 시 개선 기대 (feature_informativeness 가중치↑)
- ADR-014 §6.3은 "polluter 4/5 PASS"가 보조 기준 — 합격선 r=0.40 자체와는 분리

### POOLED r 0.389 (dataset별 0.45 × 2인데 합치면 ↓)

- 두 dataset의 score-acc 회귀선이 다른 절편/기울기를 가지기 때문 (cross-dataset linear consistency 부족)
- Heinrich 2018 R1 "cross-cell 비교 부정당" 원칙과 정합 — 보고 단위는 dataset별 r

### dead 5개 차원

- toy benchmark 한계라 정의식 자체는 학술 측정용이지 운영 의미 있는 신호 아님
- 후속 ADR에서 dataset 종속 정의식으로 교체 검토 가능 (예: outlier_ratio를 채널 평균 대신 spatial frequency 기반으로)
- 단 현재 Phase 1 합격선 통과에는 영향 없음 (offset이라 r 불변)

### 비선형 RF 5-fold R² = −0.516 (POOLED, 04 노트북 cell 3)

- DSC 점수 단일 변수로 accuracy를 비선형 회귀할 때 평균 예측보다 나쁨
- 원인:
  1. n=52 per dataset이라 RF가 두 dataset 분포를 모두 학습할 sample 부족
  2. CIFAR10/F-MNIST의 score-acc 절편/기울기가 달라 single RF가 양쪽에 fit 못 함
  3. DSC가 이미 (선형 r=0.45 수준의) 깨끗한 선형 관계라 RF의 추가 비선형 이득 없음
- ADR-015 / plan 20260511-01의 합격 단위가 **dataset별 Pearson r**이고 비선형 R²는 보조 지표라, 본 결과는 합격 판정에 영향 없음. v4 가설(H3: "비선형 우위")이 새 framework에서는 자연 해체된 항목.

### 04 노트북 cell 3의 가설 1/5 PASS — POOLED 기준 잔재

- cell 3은 v4 마스터플랜의 가설 (H1~H5: POOLED Pearson r, POOLED Spearman ρ, 비선형 우위, 모든 모델 양의 r, polluter hold-out)을 그대로 평가
- v5 framework에서 합격 단위는 **cell별·dataset별 r** (plan 20260511-01 §1, Heinrich 2018 R1 정합) → POOLED 판정은 misleading
- cell 4 (dataset별 default/tuned r) 결과가 v5 합격 단위. CIFAR10 0.449 / F-MNIST 0.447 → 둘 다 PASS
- 후속: 04 노트북 cell 3을 dataset 분리 + 모델별·polluter hold-out도 dataset 단위로 표시하도록 패치 예정

## 7. 사전등록 관점 — held-out 정의 모호함

ADR-014의 사전등록 dataset 3종 (CIFAR10/F-MNIST/Flowers102)은 **모두 튜닝 set**.
plan 20260511-01 §2-3의 정식 **held-out 후보**는 CIFAR-100 / SVHN / Caltech-101.

본 보고서의 Fashion-MNIST는 ADR-015 reframe 이전 운영 방식 (튜닝=CIFAR10, held-out=F-MNIST)을 유지한 상태이고, 엄밀히는 "튜닝 set 내 cross-validation" 성격.

→ 다음 단계에서 정식 held-out(CIFAR-100 또는 SVHN)으로 1회 측정해야 학술 정합성 완성.
