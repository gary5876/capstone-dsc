1) 이미지 cell 시범 실험 결과의 원인 진단 및 실험 setting 재정의
->
지난주 합격 기준·평가 지표·가중치·held-out 운영 방식 등 사전등록을 마치고 처음 시도한 Colab 시범 실험이 기준에 미치지 못한 상태로 마무리되어, 본 주는 그 원인 진단부터 시작하였다. 시범 실험 결과 데이터를 차원별 상관·표준편차·모델별 분리 단위로 분해해 살펴본 결과 세 가지 원인이 겹쳐 작용하고 있음을 확인하였다.
첫째, 모델 학습이 충분치 않았다. 학습 epoch이 3에 그치고 사전학습 가중치를 쓰지 않은 채 처음부터 학습하다 보니 분류 모델의 깨끗한 baseline 정확도가 낮은 상태에 머물러, 오염 데이터와 모델 성능 사이의 깨끗한 관계가 형성되지 않은 상태였다. 둘째, 표본이 부족하였다. 데이터셋당 실험 수가 적어 통계적 신뢰가 약했다. 셋째, 사전등록된 10개 품질 차원 중 5개(이미지 로드 성공률·규격 일관성·임베딩 차원 상관·중복도·intensity outlier)가 정제된 벤치마크의 특성상 항상 만점에 가까운 값이 출력되어 상관에 기여하지 못하는 상태였다.
이 진단을 기반으로 실험 setting을 보강하였다. 학습 epoch을 늘리고 ImageNet 사전학습 가중치를 사용해 backbone이 의미 있는 시작점에서 출발하도록 조정하였고, 입력 해상도는 데이터셋별로 분기해 학습 시간을 단축하였다. 오염 강도 단계도 3단계에서 5단계로 늘려 데이터셋당 표본 수를 확장하였다. 또한 임베딩 기반 품질 메트릭 3종이 같은 임베딩을 공유하도록 내부 계산을 정리해 DSC 계산 시간이 단축되었다. 사전등록된 원본 setting(epoch·모델 수 등)은 추적용으로 그대로 보존하였다.
2) 보강된 setting으로 Colab 재실험 수행 및 가중치 자동 튜닝 점검
->
보강된 setting으로 두 데이터셋(CIFAR-10, Fashion-MNIST) × 두 모델 × 26 조건에 해당하는 실험을 재수행하였다. 도중 지난주 시범 실험 시점의 옛 학습 결과 일부가 남아 새 setting으로 재학습되지 않는 동선 문제를 발견하고, 해당 부분만 백업 후 정리하여 모든 실험이 동일 setting으로 재학습되도록 보정하였다. 재실험 후 분류 모델의 깨끗한 baseline 정확도가 정상화된 것을 확인하였고, 사전등록된 default 가중치 기준으로 평가 절차를 진행하였다.
이어서 가중치 자동 튜닝의 일반화 동작도 함께 점검하였다. 항상 일정한 점수만 출력되어 사실상 효과가 없는 5개 차원은 default를 유지한 채, 살아있는 5개 차원에 대해 한 데이터셋(CIFAR-10)에서 가중치를 최적화한 뒤 다른 데이터셋(Fashion-MNIST)으로 옮겨 일반화 여부를 확인하였다. 지난주 시범 실험에서 관찰되었던 한 데이터셋에 과적합되는 양상이 사라지고 다른 데이터셋에서도 안정적으로 작동하는 동작을 확인하였다. 이 자동 튜닝 결과는 학술 검증용 reference로 보관하고, 정식 운영 단계에서 가중치 분포를 비교할 기준으로 활용할 예정이다.
3) v5 framework 합격 단위 정합화
->
가설 판정 부분에서 옛 v4 마스터플랜의 평가 기준이 일부 남아 있는 것을 함께 점검하였다. v4에서는 두 데이터셋을 합쳐 단일 상관(POOLED)으로 평가했지만, v5 framework는 cross-dataset 비교가 합당하지 않다는 학술 원칙(Heinrich 2018 R1)에 따라 데이터셋별 상관을 합격 단위로 본다. 보고 단위만 옛 형식으로 남아 있어 결과 해석에 혼동을 줄 수 있는 상태였다.
이를 보완하기 위해 평가 결과 출력을 데이터셋별 단위로 재구성하였다. 데이터셋별 상관 → POOLED 보조 → 모델별 상관 → 오염 종류 제거 시 안정성 → v5 단위 합격 판정 순서로 분리하였고, POOLED와 비선형 모델 적합도 결과는 보조 지표로 남기되 합격 단위가 아님을 명시하였다. 비선형 모델의 결과도 표본 수와 두 데이터셋 분포 차이에 따른 자연스러운 결과로 해석을 정리하였다. 다음 주는 학술적으로 더 엄밀한 정식 held-out 데이터셋(CIFAR-100 등) 측정과, 효과 없는 5개 차원의 정의식 보완을 후보로 두고 진행 방향을 결정할 예정이다.
