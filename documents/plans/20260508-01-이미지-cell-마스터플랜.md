### 2-2. Polluter PyTorch Dataset Wrapper

기존 tabular polluter는 DataFrame 입력. 이미지 polluter는 PyTorch Dataset wrapping 패턴:

```python
class ImagePollutedDataset(torch.utils.data.Dataset):
    def __init__(self, base_dataset, polluter, level, random_seed):
        self.base = base_dataset
        self.polluter = polluter
        self.level = level
        self.indices = polluter.select_indices(len(base_dataset), level, random_seed)

    def __getitem__(self, i):
        img, label = self.base[i]
        if i in self.indices:
            img = self.polluter.apply(img, self.level)
        return img, label
```

5개 polluter:
- `CompletenessImagePolluter` — 픽셀 마스킹
- `NoiseInjectionPolluter` — Gaussian noise
- `BlurPolluter` — Gaussian blur
- `ClassBalanceImagePolluter` — undersampling
- `LabelSwapPolluter` — label noise

**중요**: Colab GPU 세션 끊어짐 대응. `03_training_image.ipynb`은 체크포인트 메커니즘이 핵심 (회귀 cell보다 더 중요 — 1 fit이 5~15분).

GPU 권장 사양:

- 권장: L4 (Colab Pro+)
- ViT-Tiny는 V100/A100이 빠름

### 검증 기준 (Phase 2 통과)

| 가설 | 기준 |
|---|---|
| H1: Pearson r(DSC, accuracy) ≥ 0.4 | 회귀와 동일 |
| H2: Spearman ρ ≥ 0.4 | 회귀와 동일 |
| H3: 비선형 RF 5-fold R² > r² | 회귀와 동일 |
| H4: 모든 모델에서 양의 r | 회귀와 동일 |
| H5: Polluter hold-out 4/5 PASS | 회귀와 동일 |

- input이 pandas DataFrame → 'tabular'

def detect_data_type(input):
    import torch
    if isinstance(input, torch.utils.data.Dataset):
        return 'image'
    if hasattr(input, 'columns'):  # DataFrame-like
