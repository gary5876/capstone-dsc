2. 캡스톤 발표용은 cell당 1개만 측정 (보존 활용)

4. 측정 산출물은 §4 디렉토리 구조로 git commit (reproducibility)

## 3. LLM 호출 freeze 정책

### 3-1. freeze 시점

held-out 측정 *직전*에 본 §3의 모든 항목 freeze. 측정 이후 변경 시 후속 ADR 필요.

### 3-2. freeze 항목 (held-out 측정 시 measurement_meta.json에 명시)

| 항목 | 기본 후보 (held-out 측정 전까지 변경 가능) |
|---|---|
| LLM provider | Anthropic |
| Model ID | `claude-sonnet-4-6` |
| Temperature | 0 |
| Max tokens | 1024 |
| Prompt version | v1 |
| Prompt template path | `dsc_framework/prompts/weight_generator_v1.txt` |
| Weight bounds | [0.01, 0.60] (ADR-015 §4.위험3) |
| Sum tolerance | ±0.01 |
| Same-input N (가중치 분산 측정용) | 10 |

### 3-3. 튜닝 단계 자유도

held-out 측정 *전*에는 다음 모두 자유:
- prompt template 수정 (단, 버전 번호 갱신 — v2, v3, ...)
- LLM provider / model / temperature / max_tokens 변경
- fallback 가중치는 ADR-009 / 011 / 014 사전등록 값 유지 (가중치 freeze 해제는 *LLM 출력*에만 적용, fallback 정의는 보존)

### 3-4. dataset metadata 입력 명세 (LLM에게 전달, 실측 label/오염 정보 차단)

LLM에게 전달하는 dataset metadata:

```json
{
  "schema": {"col_name": "dtype", ...},
  "n_rows": N,
  "n_cols": N,
  "target_col": "...",
  "task": "classification|regression",
  "feature_stats": {
    "numerical": {"col": {"mean": x, "std": x, "missing_rate": x, "skew": x}},
    "categorical": {"col": {"n_unique": x, "missing_rate": x, "mode_freq": x}}
  },
  "target_summary": {
    "classification": {"n_classes": x, "class_balance_entropy": x, "majority_freq": x},
    "regression": {"min": x, "max": x, "mean": x, "std": x, "skew": x, "n_bins_quantile": 10}
  }
}
```

차단 항목 (LLM에게 절대 전달 금지):
- 실측 label 값 분포의 ML 성능 추정
- 오염(polluter) 적용 여부 / 강도
- 기존 DSC 점수 결과 / r 결과

## 4. 측정 산출물 위치 (reproducibility)

held-out 측정마다 다음 구조로 git commit:

```
dsc/results/heldout/
  <YYYYMMDD>_<cell>_<dataset>/
    measurement_meta.json     # §3-2 freeze 항목 + git commit hash + 측정 일자
    llm_raw_responses.jsonl   # LLM 호출 raw log (입력+출력+model+temp+token usage)
    weights_used.json         # 검증된 가중치 또는 fallback 사용 표시
    dsc_scores.csv            # DSC 점수 (setting × dataset 단위)
    model_performance.csv     # 모델별 R²/accuracy/F1
    merged_results.csv        # 표본 단위 통합
    r_report.md               # Pearson/Spearman/p + 합격선 비교 + pass/fail
    weight_variance.csv       # N=10 호출의 가중치 분산 (§1 합격 조건)
```

**`measurement_meta.json` 스키마**:

```json
{
  "cell": "tabular_classification | tabular_regression | image_classification",
  "dataset": "...",
  "is_heldout": true,
  "measurement_date": "YYYY-MM-DD",
  "git_commit": "<sha>",
  "llm": {
    "provider": "Anthropic",
    "model": "claude-sonnet-4-6",
    "temperature": 0.0,
    "max_tokens": 1024,
    "prompt_version": "v1",
    "prompt_path": "dsc_framework/prompts/weight_generator_v1.txt",
    "weight_bounds": [0.01, 0.60],
    "sum_tolerance": 0.01
  },
  "acceptance_threshold": 0.50,
  "result_r": 0.0,
  "result_p": 0.0,
  "result_spearman": 0.0,
  "passed": false,
  "fallback_count": 0,
  "fallback_rate": 0.0,
  "weight_cv_max": 0.0,
  "n_samples": 0
}
```

## 5. 검증 원칙 (CLAUDE.md 준수)

1. **외부 dataset 라이선스 검증**: §2의 "⏳" 표시 모두 Phase 진입 시 출처 페이지 직접 확인. 비호환 시 후속 ADR로 dataset 교체
2. **외부 LLM API 사전 검증**: Anthropic API 실제 호출 sanity check (튜닝 set 1 dataset으로). 환경 설정(API key, anthropic SDK 설치)은 사용자 책임
3. **사전 등록 freeze**: held-out 측정 이후 본 plan §1~§3 변경 시 후속 ADR 필요. 측정에 사용된 held-out dataset은 자동 강등
4. **측정 raw log git commit**: §4 디렉토리 구조 그대로. reproducibility 확보 (ADR-015 §6.7)
5. **실측 label/오염 정보의 LLM 격리**: §3-4의 "차단 항목" 절대 준수 — 같은 dataset에서 튜닝/보고 동시 금지 원칙의 운영 가드레일
