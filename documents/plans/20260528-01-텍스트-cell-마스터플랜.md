### 2-2. CPU sanity check 결과

`python _dev/sanity_text_cell.py` (use_embeddings=False, n=120 가짜 corpus):

- clean DSC: 분류 99.21 / 회귀 99.13 (모두 A)
- 7 polluter 모두 정상 실행 (dq4ai patch 적용 후)
- 의도된 메트릭 단조 감소 확인:
  - completeness_text 0.5 → completeness_text 1.000 → 0.499 (ΔDSC -8.58)
  - class_balance 0.5    → class_balance 1.000 → 0.533 (ΔDSC -4.71)
  - label_swap 0.3       → class_balance 1.000 → 0.800 (ΔDSC -2.00)
  - target_noise 0.5     → target_distribution_quality 0.992 → 0.897 (ΔDSC -0.95)
- word_shuffle / noise_injection은 BoW 메트릭에선 변동 작음 (의도된 동작 — embedding 활성 시에만 큰 영향. Phase 2에서 확인)

## 3. Phase 2 — 데이터·학습·검증 (진행 대기)

### 3-1. HuggingFace datasets 로딩

```python
from datasets import load_dataset

# 분류 트랙 (ADR-016)
ag_news = load_dataset('fancyzhx/ag_news')                # 120K + 7.6K, 4-class
imdb    = load_dataset('stanfordnlp/imdb')                 # 25K + 25K,  binary
news20  = load_dataset('SetFit/20_newsgroups')             # 11.3K + 7.5K, 20-class

# 회귀 트랙 (ADR-017)
yelp    = load_dataset('Yelp/yelp_review_full')            # 650K + 50K, 5-star
amazon  = load_dataset('mteb/amazon_reviews_multi', 'en')  # 200K + 5K,  5-star
sst5    = load_dataset('SetFit/sst5')                      # 8.5K + 2.2K, 5-class ordinal
```

**샘플링 (ADR-017 §4 사전등록)**:
- Yelp/Amazon: train 50K stratified / test 5K stratified, random_state=42
- 그 외: 전체 사용

### 3-2. 모델 학습 루프

이미지 cell 마스터플랜의 학습 루프 패턴(`train_model(model, dataset, epochs, lr) → metric`)을 텍스트로 이식. transformer 3종(DistilBERT/BERT/RoBERTa)은 HuggingFace `AutoModelForSequenceClassification` + `Trainer`. baseline 2종(LogReg+TFIDF / TextCNN / Ridge+TFIDF / XGBoost+TFIDF)은 scikit-learn / xgboost / 직접 PyTorch.

분류·회귀 트랙에서 transformer 2종(DistilBERT, BERT-base) 공유 가능 — head만 분류/회귀 교체. 학습 시간 절약.

**예상 GPU 시간 (T4 기준)**:
- transformer 1 finetune (max_len 256, batch 32, epoch 3): 5~20분
- 분류 트랙: 3 dataset × 5 model × 5 polluter × 6 level + 18 baseline = 468건 → 30~50시간
- 회귀 트랙: 동일 468건 → 30~50시간 (Yelp 50K sample 적용 후)
- 합산 60~100시간. Colab Pro+ 또는 Pay-as-you-go GPU 예산.

### 3-3. 4단계 노트북 (분류·회귀 별도 또는 합본)

이미지 cell 노트북 패턴 미러:
- `01_dsc_measure.ipynb`: 6 dataset × 6 level × 5 polluter → DSC + polluter_quality 측정
- `02_model_train.ipynb`: 6 dataset × 5 model × 5 polluter × 6 level → accuracy/R² 수집
- `03_meta_validation.ipynb`: r(DSC, metric), polluter hold-out, 모델별 r 분석
- `04_weight_tuning.ipynb`: default 가중치 r → grid search → tuned 가중치 r 비교 → LLM 가중치 생성 입력 sanity

### 3-4. 검증 통과 기준 (Phase 2 종료 조건)

각 트랙(분류/회귀) 별로:
- Pearson r(DSC, target) ≥ 0.4 (튜닝 set 각 데이터셋별)
- Spearman ρ ≥ 0.4
- Polluter hold-out 4/5 PASS
- 모델 5/5 양의 r
- POOLED는 보조 (Heinrich 2018 R1 — cross-dataset 비교 부정당)
- 회귀 트랙은 추가로 ADR-012 Degradation Index `m_deg` 보고
