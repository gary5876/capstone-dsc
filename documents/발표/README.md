## 서사 방향 (요약)

- 처음부터 6셀 framework를 목표로 한 흐름으로 구성.
- 중심 축: **왜 시작했나** + **어쩌다 이 DSC framework가 됐나**.
- 엔진 실패→수정(r=0.085 → 0.598) 경험을 framework가 task-conditional·reference-free·사전등록 구조가 된 근거로 배치.
- 결과 수치는 정식으로 제시(측정 기준 함께 표기). 6셀 전부 상관 확인(정형 회귀 r=0.566 포함).
